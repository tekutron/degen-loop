### Technical Implementation

```javascript
async getMoralisPrice(tokenMint) {
  const response = await fetch(
    `https://solana-gateway.moralis.io/token/mainnet/${tokenMint}/price`,
    {
      headers: { 'X-API-Key': MORALIS_API_KEY }
    }
  );
  return { price: data.usdPrice, source: 'moralis' };
}
```

## Key Learnings

### Position Sizing Issue
**Problem:** Small positions (0.01 SOL) make fees disproportionately large
- Trade #1: +16% profit, but fees took ~15-20% overhead
- Need larger positions to make fees proportionally smaller

**Solutions:**
1. **Increase to 0.05 SOL positions** (5x larger)
   - Fees become 1/5th the percentage impact
   - Example: 0.006 SOL fees on 0.05 SOL = 12% vs. 60% on 0.01 SOL
2. **Increase TP target** (10% → 15% or 20%)
   - Bigger wins to overcome fees
3. **Trade less frequently** (higher quality filter)
   - Fewer trades = fewer fees

### Market Quality
- **Sunday evening:** Low quality, 0.4% execution rate
- **Recommendation:** Test during US weekday hours (Mon-Fri 9am-4pm EST)
- More legitimate projects launch during business hours

### Configuration Optimal Settings
**Current (working well):**
- Age filter: 1s (fast entries)
- TP: 10% (realistic target, got hit)
- SL: 10% (1:1 ratio, fair)
- Slippage: 5% (tight but working)

**Recommendations:**
- Position size: 0.01 → **0.05 SOL** (minimize fee impact)
- Or TP: 10% → **15%** (bigger wins to cover fees)
- Keep everything else the same
