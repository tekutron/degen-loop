## Bonding Curve Detection & Price Monitoring (Evening Session ~22:00 PST)

### Critical Implementation: Bonding Curve vs DEX Detection

**Problem Identified:**
- Tokens launch on pump.fun bonding curve (not yet on DEX)
- DexScreener only tracks DEX pools, not bonding curves
- Result: Fresh tokens show $0 liquidity → false rejections

**Solution Implemented** (commit 319b1d6):
- Added `checkBondingCurveStatus()` to safety-checker.mjs
- Fetches bonding curve account from pump.fun program
- Detects if token still on bonding curve vs. graduated to Raydium
- Skips DEX liquidity checks for bonding curve tokens

**Code Logic:**
```javascript
const isBondingCurve = await checkBondingCurveStatus(tokenAddress);
if (!isBondingCurve) {
  // Only check DexScreener liquidity for graduated tokens
  const dexData = await checkDexScreenerData(tokenAddress);
  if (dexData.liquidity < MIN_LIQUIDITY_USD) {
    return { passed: false, reason: 'LOW_LIQUIDITY' };
  }
}
// Bonding curve tokens bypass liquidity check
```
