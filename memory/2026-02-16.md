- **Complexity:** Pool keys, market IDs, vault addresses required

### Dashboard Architecture
- **Backend:** Express HTTP server + WebSocket
- **Frontend:** Vanilla JS (no framework)
- **State sync:** Server polls state files every 5s, broadcasts via WS
- **Balance fetching:** Spawn child process (blockchain queries are slow)

### Token Account Management
- **USDC ATA:** Created automatically by Jupiter on first swap
- **Cost:** ~0.002 SOL rent (one-time)
- **Finding ATA:** `getAssociatedTokenAddress(mint, owner)`
- **Reading balance:** `getAccount(connection, ata)`
- **Error handling:** Missing account = 0 balance (not an error)

### wickbot Strategy Optimizations (Commits 6759898, 57a35b7)

**Problem:** Bot too conservative - refused oversold entries due to bearish patterns

**Solution: Multi-layered strategy improvements**

#### 1. RSI Threshold Adjustments
**Changed:**
- `RSI_OVERSOLD: 40 → 30` (more extreme oversold)
- `RSI_OVERBOUGHT: 60 → 70` (more extreme overbought)

**Rationale:**
- 40/60 = moderately oversold/overbought
- 30/70 = **classic TA levels** (extreme conditions)
- More selective entries = higher quality signals

#### 2. MA Crossover Filter (Trend Confirmation)
**Added:** `checkTrend()` method in `signal-generator.mjs`

**Logic:**
```javascript
// Golden Cross = bullish trend
if (price > ma20 && ma20 > ma50) return 'bullish'

// Death Cross = bearish trend  
if (price < ma20 && ma20 < ma50) return 'bearish'

return 'neutral'
```

**Integration:**
- BUY signals require `trend === 'bullish'`
- SELL signals trigger on `trend === 'bearish'`
- Prevents counter-trend entries

**Why it matters:** Confirms trend direction before entry, avoids "catching falling knives"

#### 3. Signal Scoring Rebalance
**Changed weights:**
- Indicators: `30% → 40%` (trend matters more)
- Patterns: `70% → 60%` (patterns less dominant)
- Multi-timeframe bonus: `20 → 25`
- **Min score:** `70 → 75` (more selective)

**Effect:** Requires stronger alignment between indicators and patterns

#### 4. Pattern Weight Optimization
**Reorganized by reliability:**

**Strong patterns (88-95 weight):**
- three_white_soldiers (95) - extremely bullish
- three_black_crows (95) - extremely bearish
- engulfing_bullish/bearish (90/88) - strong reversal

**Medium patterns (70-80 weight):**
- hammer (80) - bullish reversal
- morning_star (78) - bottom reversal
- doji (70) - indecision

**Weak patterns (35-68 weight):**
- spinning_top (45) - indecision
- marubozu_bullish/bearish (68/65) - continuation
- hanging_man (60) - bearish reversal

**Why it matters:** Weights match proven TA reliability, stronger patterns have more influence

#### 5. More Conservative Entry Logic
**Now requires:**
- Pattern detected
- Indicator confirmation (RSI/MACD/Volume)
- **Trend alignment** (new!)
- Score ≥ 75 (raised from 70)

**Expected Results:**
- Fewer trades (2-5/day → 1-3/day)
- Higher win rate (targeting 60-70%)
- Better risk/reward (trend-aligned entries)
- Fewer false signals
