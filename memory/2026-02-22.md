### How It Works

**Example flow:**
1. Scan for crypto markets
2. For each market:
   - Fetch BTC/ETH/SOL price data
   - Analyze momentum, social sentiment, on-chain
   - Calculate weighted prediction
   - Compare to market odds
3. If edge ≥10% + confidence ≥70% → Place bet
4. Position size via Kelly Criterion

**Risk management:**
- Max $10 per bet
- Min 10% edge required
- Min 70% confidence
- Diversification across markets
