## Technical Implementation

### Prediction Algorithm
```javascript
// For 5-minute markets, momentum is key
1. Fetch real-time price from CoinGecko
2. Estimate 1m/3m/5m momentum from 1h data
3. Classify trend: STRONG_UP, UP, NEUTRAL, DOWN, STRONG_DOWN
4. Assign confidence based on trend strength
5. Calculate edge (our prediction vs 50/50 market odds)
6. Recommend bet when edge ≥5% + confidence ≥60%
```

**Example:**
- 5m momentum: +0.8% → STRONG_UP trend
- Confidence: 75%
- Edge: +15% (predict 65% UP vs 50% market)
- **Recommendation:** BET UP ($10)

### Polymarket 5-Min Markets
**Lesson #128:** Polymarket has 5-minute crypto markets at /crypto/5M, not obvious from API structure.

**Lesson #129:** Markets run in time-specific windows with new markets created every 5 minutes.

**Lesson #130:** API doesn't tag them as "5M" directly - must search by series slug patterns.

### Prediction Strategy
**Lesson #131:** 5-minute markets need fast-reacting signals - momentum more important than fundamentals.

**Lesson #132:** CoinGecko doesn't provide 1m data - must estimate from 1h data (limitation).

**Lesson #133:** Binary Up/Down markets at 50/50 baseline → any edge >5% is significant.

### Wallet Security
**Lesson #134:** Polygon wallet uses same format as Ethereum (different from Solana ed25519).

**Lesson #135:** File permissions (0600) critical for private key storage.

**Lesson #136:** Separate wallets per blockchain = good security practice.
