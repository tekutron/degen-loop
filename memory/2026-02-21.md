## Critical Price Data Bug (4:05 PM)

**Trade #83 Failed:**
- Entry: Correct (dip -2.61%, wick L=65%) ✅
- Exit: False SL trigger (-17% shown, -2% expected) ❌
- Actual loss: -17.27% (not -2%)

**Root Cause:** Price data mismatch
- Entry price: $0.000128 (from real Jupiter swap) ✅
- Current price: $0.000106 (from DexScreener synthetic candles) ❌
- Bot calculated: -17.27% loss (triggered SL immediately)
- Jupiter quote: -1.59% actual market loss
- Deviation: 15.69% (data completely wrong)

**What happened:**
1. Bot entered at real price $0.000128
2. Monitoring used stale candle data showing $0.000106
3. Bot thinks: -17% loss → trigger SL
4. Tries to sell, Jupiter says "only -1.59% loss"
5. Bot sees huge deviation, retries multiple times
6. Eventually force-sells at -17% actual loss

**The Problem:** 
DexScreener synthetic candles are built from trade aggregation, not real-time quotes. They lag significantly on low-liquidity tokens.

**Fix Applied:**
- Stop using `candle.close` for position P&L monitoring
- Use Jupiter `getQuote()` for real-time market price every cycle
- Calculate: SOL received / tokens sold = current price
- Fallback to candles only if quote fails

**Testing:** Need clean test to verify real-time quotes work correctly.

## Trailing Stop Implementation (4:48 PM)

**Trade Analysis Trades #87-93:**
- Win rate: 43% (3/7)
- Avg win: +2.81% | Avg loss: -4.27%
- Session: -12.5% (0.0552 → 0.0483 SOL)

**Key Finding:**
- All wins hit +2% TP1 then exited
- Token pumped to +42% (1h momentum)
- Trade #90: Took +2.94%, left +19% on table (could have been +21.9%)
- Current price $0.0001487 is HIGHER than ALL our exits

**Problems Identified:**
1. **Exiting too early** - Missing big trends after +2%
2. **-2% SL too tight** - Instant -8% stops in volatile conditions
3. **Risk/reward broken** - Need 1.5 wins per loss at 43% WR

**Solution Implemented:**

**1. Trailing Stop:**
```javascript
ENABLE_TRAILING_STOP: true
TRAILING_ACTIVATION: 2.0%    // Start at +2% profit
TRAILING_DISTANCE: 1.0%      // Trail 1% behind peak
```

**How it works:**
- Hit +2% → activate trailing (no fixed exit)
- Track peak price continuously
- Exit if price drops 1% from peak
- Example: +2% → +5% peak → exit at +4%

**2. Wider Stop Loss:**
```javascript
QUICK_SL: 2.0 → 3.0%
```
- Gives volatile tokens more room
- Reduces instant -8% false stops
- Better risk/reward: 3:1 at +3% target

**Expected Impact:**
- Capture more of trending moves (would have gotten +4-10% on #90)
- Reduce false SL triggers
- Better win/loss ratio
- Keep quick TP2 (+4%) for fast exits
