## Bugs Found & Fixed (5 Total)

### 1. Slippage Catastrophe
**Problem:** -8.67% loss when expecting -2% SL (no caps)
**Root Cause:** No slippageBps parameter = Jupiter accepts ANY price
**Fix:** Adaptive slippage (2% profit, 3% loss, 10% emergency)
**Impact:** Prevented future -6% surprise losses

### 2. Entry Confirmation "Reset Trap"
**Problem:** Missed $0.000746 → $0.000800 pump (waiting for 5% dip)
**Root Cause:** "Recent high" reset after exits → locked out of pumps
**Fix:** Momentum-based entry (>0%, red filter, volume spike)
**Impact:** +21% better session performance

### 3. Dashboard Server Crash
**Problem:** Syntax error on startup (orphaned code)
**Root Cause:** Duplicate return statement outside function
**Fix:** Removed orphaned code block
**Impact:** Dashboard now starts cleanly

### 4. Momentum Calculation Bug
**Problem:** Bot looking for non-existent signal.momentum1m field
**Root Cause:** FastSignalGenerator doesn't calculate momentum
**Fix:** Calculate from candles (current vs 2 candles ago)
**Impact:** Entry filter now actually works

### 5. MAX_POSITIONS Race Condition
**Problem:** Bot opening 2-3 positions when limit is 1
**Root Cause:** Async gap between check and execution
**Fix:** Double-check positions.length right before executeBuy()
**Impact:** Enforces risk management properly

## Key Lessons Learned

### On Debugging
1. **Data-driven debugging works** - Trade logs revealed exact failure patterns
2. **Live testing > simulation** - Morning tests perfect, afternoon found race bug
3. **Root cause > symptoms** - Fixed slippage at Jupiter params, not band-aids
4. **One bug = multiple bugs** - Saw 2 positions once → fixed immediately

### On Strategy Development
5. **Rapid iteration beats planning** - 6 hours from -1.88% to +19.29%
6. **Validate with real money** - Paper trading can't test execution/slippage/races
7. **Know when validated** - Expected 60-70% → Got 62.5% → Hypothesis confirmed
8. **Document during iteration** - 8 analysis docs enable learning

### On Concurrency
9. **Race conditions hide in async gaps** - Check + async + execute = window for race
10. **Double-check critical invariants** - Redundant checks prevent catastrophe
11. **hasMaxPositions() not enough** - Need inline check at execution point
