## 4. Learning & Growth 📚

**Critical Technical Lessons:**
1. **Blockchain signatures ≠ confirmation** - Must explicitly wait for on-chain finality
2. **Rate limits are real** - 100ms polling = instant 429 errors
3. **Undocumented APIs are dangerous** - Pump.fun program specs unclear
4. **Async operations need explicit waits** - `sendTransaction()` returns before tokens arrive

**Strategic Lessons:**
1. **Reliability > Speed in production** - 0% success at 300ms vs. 100% at 800ms
2. **Know when to pivot** - 60 failures = clear signal to switch
3. **Use proven infrastructure** - Jupiter is battle-tested vs. pump.fun experimentation

**Growth Evidence:** Started day celebrating "clever" solution, ended by choosing "boring" reliability. That's maturity.
