### Lessons Learned
- **Browser caching blocks fixes** - Always hard refresh (Ctrl+Shift+R) after code changes
- **Check browser console** - Syntax errors prevent entire script from loading
- **WebSocket localhost assumption breaks remote access** - Use `window.location.host` for auto-detection
- **Orphaned code after function stubs** - Common refactoring mistake, creates syntax errors
- **When users report "nothing happens"** - Check browser console first (DevTools F12)
